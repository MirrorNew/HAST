# Main Artifacts

This directory is the local single source of truth for paper-facing data and figures.

- `source_tables/benchmark_12graph/`: 12-graph benchmark metrics, per-network point-evaluation tables, and main-result summaries used by Section 5.2. Each network has its own `point_evaluations/` folder.
- `source_tables/motivation_observation/`: motivation-section case-selection and diagnostic CSVs used by Chapter 3 figures.
- `source_tables/search_runtime/`: search-framework runtime and per-candidate timing summaries used by Section 5.2.4.
- `source_tables/scaling/`: full-evaluation and runtime-only scaling tables used by Section 5.5.
- `source_tables/hast_search_evidence/`: retained HAST/search candidate records that still contain HAST-related evidence and may be replaced after reruns.
- `figures/`: figures regenerated by `scripts/regenerate_record_based_figures.py`.
- `reports/`: optional local audit or provenance reports.

Large CSVs and generated figures are intentionally ignored by Git. The tracked scripts and index documents describe how to regenerate or validate them.
